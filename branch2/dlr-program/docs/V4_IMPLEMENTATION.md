# V4 rolling 구현 및 대화 합의 (2026-10-28)

기준은 저장소 루트의 DLR_PROGRAM_ARCHITECTURE_V4_ROLLING_INITIAL_TEMP_INTEGRATED.md와 다음 합의다.
V3와 이전 구현 상태 문서는 이전 버전의 기록이다.

- 위험 기준은 각 1시간에 독립 적용한다. 24시간 전체 위험 한계나 열화 예산을 적용하지 않는다.
- 각 시간에서 허용 가능한 최대전류를 선택한다. 이후 시간의 여유를 예약하지 않는다.
- 사용자가 매시간 권고전류를 모두 사용한다고 가정한 전망이다. 실제 전류 수집·자동 운영 갱신은 없다.
- Tmax 초과확률과 그 시간 추가 열노화의 분위수 제약을 동시에 검사한다.
- 기댓값 및 열화 증가율은 추가하지 않는다. 기상 시나리오와 임시 열노화 지표는 이전 정의를 유지한다.
- SLR/DLR은 같은 최초 온도에서 시작하고 각자의 시나리오별 종료온도를 이어간다.
- 추가 열노화는 각 시간의 D_DLR - D_SLR로 계산한다. 이전 시간의 열노화를 판정에 더하지 않는다.
- 해가 없으면 전류 0 A, status=infeasible, safe=false를 표시하고 0 A 종료온도로 다음 계산을 계속한다.

## 입력

미래 기상 JSON은 기존 [N, 경간, 구간] 배열 계약을 유지하며 정확히 24시간을 포함해야 한다.
1시간 경계와 기상 구간 경계가 달라도 기존 구간의 값을 유지하면서 경계를 나눈다.
시나리오 순서와 경간 순서를 바꾸거나 새 표본을 생성하지 않는다.

최상위 `historical_weather`를 추가할 수 있다. 미래 기상과 같은 스키마지만 시나리오는 1개이며
종료시각이 미래 예측 시작시각과 같아야 한다. 이 자료는 과거 기상 이력이다.
과거 전류는 사용자 합의에 따라 전 구간 SLR 최대허용전류를 사용했다고 가정한다.
예제는 합성 과거 기상을 포함한다. 실제 사용자 전류 이력 입력 기능은 이번에 만들지 않는다.

## 초기화 설정

config.initialization: mode=warmup, start_hours=1, extension_hours=1, max_hours=12,
low_temperature_c=0, tolerance_c=1. 모두 변경 가능하다.
Tmax와 낮은 온도에서 과거 transient 계산을 시작해 종료온도 차이가 모든 경간에서 1°C 이하이면
더 높은 결과를 사용한다. 미수렴이면 과거 범위를 늘려 처음부터 재실행한다.
과거 부족 시 Tmax를 사용한다. 미수렴 시 Tmax와 마지막 두 계산 종료온도 중 최대값을 사용하여
이미 계산상 Tmax를 넘는 온도를 임의로 낮추지 않는다. status와 시도별 차이를 기록한다.
manual 모드는 config의 경간별 initial_temperature_c를 직접 사용하는 개발/추후 연계용 경로다.

## 출력과 UI

schema_version=2.0. `current_recommended_DLR`은 첫 1시간 전류이며,
`hourly_DLR_trajectory_24h`는 24개 숫자다. `hourly_results`에 매시간의 risk curve,
온도 시작/종료, Tmax 위험, 손상 표본, 탐색 기록, 안전 여부를 보관한다.
`hourly_time_edges`는 25개 시각이다. 최상위 기존 결과 필드는 첫 시간의 결과다.
`initialization`에는 초기온도·수렴 상태·과거 사용전류가 기록된다.
UI의 24시간 그래프와 시간 선택기를 통해 각 시간의 결과를 조회한다.
미래 24시간을 하나의 고정전류로 표시하거나 24시간 전체가 같은 위험수준이라고 해석하지 않는다.

## 실행/검증

실행 방법은 README와 같다. 서버가 이전 버전으로 실행 중이면 종료 후 재실행해야 한다.
기존 단일 고정전류 검사는 run_fixed_engine을 사용한다. V4 검사는 시간 경계 분할,
독립 상태 연결, 0 A 대체, 한 시간 손상 차이, warm-up 수렴 및 과거 부재를 확인한다.
실제 도체 물리 기준사례 검증과 실제 기상모델 calibration은 이번 범위 밖이다.

실행 확인: Python 검사 25개 통과, UI 로직 검사(24개 시간 선택·그래프 포함) 통과. 합성 64개·2경간·24시간 CLI 계산 26.2초, 초기 warm-up 1시간에서 모든 경간 1°C 이내 수렴. 23개 시간 경계의 DLR 온도 연속성 확인. 실제 브라우저 레이아웃 재검증은 이번 수정에서 수행하지 않음.
