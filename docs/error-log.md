# 오류 기록

AI나 사람이 잡은 오류를 한 줄씩 적는다. 같은 유형이 두 번 나오면 `validation/`에 테스트로 바꾼다.

|---|---|---|---|---|---|---|---|---|

## 유형 (하나를 고른다)
- **단위**: MJ/m² ↔ W/m², m/s, ℃·K, Ω/km 등 변환 오류
- **시간**: KST·UTC 혼동, 1~24시 표기, 선행시간(`lead_hour`) 어긋남, **t시 업데이트에 t시 이후 데이터 사용(미래 누설)**, 시나리오별 도체온도를 이어받지 않음(평균값으로 넘김 등)
- **부호·정의**: `error = actual - forecast` 부호 반대, 풍향 기준(불어오는 방향, 북 0°, 시계 방향)이나 경간 방위각 오류
- **수식**: IEEE 738 항(qc·qr·qs·I²R) 오류, 891A 테스트 실패(허용 오차 ±1% 밖)
- **상수**: `config/` 값과 다른 숫자를 코드에 직접 씀
- **입출력**: 브랜치 사이 이름이나 열 이름(`scenario_id`, `time`, `air_temperature`, `wind_speed`, `wind_direction`, `solar`, `span_id`, `lead_hour`) 불일치
- **시나리오**: 시간 독립 추출, 시드 미고정으로 결과가 매번 달라짐, 모델을 임의로 고정함
- **열화·리스크**: 시간당 위험과 24시간 전체 위험 혼동, SLR과 DLR을 다른 시나리오로 비교, ΔD 부호 오류, 분위수(q99 등) 계산 오류, 열화 식 출처 없음
- **데이터**: 결측·이상값 처리 누락, 지점·경간 매칭 오류
- **보고**: 돌리지 않은 테스트를 통과했다고 하거나, 수치를 지어냄
