## 현재 구현한 임시 열노화 지표

강도손실을 나타내지 않는 **기준온도 환산시간**을 사용합니다.

`a(T) = exp[(Ea/R) × (1/Tref_K - 1/T_K)]`

`D = integral(a(T(t)) dt_hours)`

활성화에너지 Ea=80,000 J/mol와 기준온도 100°C는 **구동 예제 가정**이며 ASCC/TW의
검증된 재료계수가 아닙니다. 수치 적분 시 각 단계 양 끝의 rate를 사다리꼴 적분합니다.
과거 운전 이력을 보관하거나 장기 잔여수명을 예측하지 않고, 이번 예측구간만 평가합니다.

SLR과 후보전류에 동일한 모델·초기온도·기상 시나리오를 사용하며,
각 시나리오·경간에 대해 `ΔD = D_candidate - D_SLR`을 계산합니다.
SLR보다 낮은 전류에서 생기는 음의 ΔD도 보존합니다. 크기/비율 혼동을 피하기 위해
SLR 열화가 0에 가까울 때 불안정해지는 ΔD/D_SLR 비율은 계산하지 않습니다.

이 모델의 위험곡선은 **기상 시나리오 조건부 모델 지표 초과확률**입니다.
열화모델 계수 불확실성이나 실제 단선확률은 포함하지 않습니다.
